# 🧩 CruciWord

**CruciWord** es una Aplicación Web Progresiva (PWA) educativa, minimalista y accesible, diseñada para la memorización de vocabulario en inglés mediante crucigramas con propósito. Su enfoque inclusivo abarca desde niños que inician su lectoescritura hasta adultos mayores, ofreciendo una experiencia libre de presiones, notificaciones persecutorias o cronómetros punitivos.

## 🚀 Stack Tecnológico
- **Backend:** Python 3.11+ con FastAPI
- **Base de Datos y ORM:** PostgreSQL (Neon) + SQLAlchemy + Alembic (migraciones)
- **Frontend:** HTML5 + Tailwind CSS + JavaScript vainilla (Mobile-First y diseño responsivo)
- **Accesibilidad y Audio:** Web Speech API nativa (bajo clic) y diseño de alto contraste con estética de cómic/revista de pasatiempos.

## 🎯 Filosofía de Producto
- **Modelo Pull:** Cero fricción, avance a tu propio ritmo.
- **Independencia Total:** Cero llamadas a APIs externas de Inteligencia Artificial en tiempo de ejecución.
- **Extensibilidad:** Arquitectura desacoplada preparada para soportar futuros juegos lúdicos y competencias grupales.
